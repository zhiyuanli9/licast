# LiCast - Python Screen Mirroring Tool

LiCast is a screen mirroring application built with Python. It allows you to cast your phone screen to your computer without installing any additional software on your mobile device. The interface is fully localized in Chinese.

# LiCast - Python 投屏工具

LiCast 是一款基于 Python 开发的投屏程序。它可以将你的手机屏幕投射到电脑上，手机端无需安装任何额外的软件。软件界面为全中文。
